# KnowMate v0.9 固定 RAG 主链路 TASK 提示词

日期：2026-06-06

用途：本文件用于在新的 Codex 对话里逐个复制 TASK 提示词执行。范围来自 `docs/v0.9.md`，目标是把 KnowMate v0.9 从“可配置实验型 RAG”收敛为一条固定、可解释、可调优的 Quick Q&A 主链路。

v0.9 固定主链路：

```text
文件上传
-> 文档解析
-> 文本清洗 / Markdown 标准化
-> parent-child 结构化切分
-> child chunk 写入 PostgreSQL
-> child chunk 写入 Qdrant 向量索引
-> child chunk 写入 PostgreSQL + ParadeDB BM25 关键词索引
-> 用户提问
-> query rewrite / query normalize
-> Qdrant 向量召回 top50
-> ParadeDB BM25 关键词召回 top50
-> RRF 融合 top30
-> rerank 强制重排 top8
-> parent context 扩展
-> 上下文去重 / 压缩 / 编号
-> LLM 生成答案
-> 返回 answer + sources + retrieval trace
```

明确排除：

- 不做 Auth / RBAC-lite / 多租户成员体系。
- 不做 Agent Mode、Wiki Mode、GraphRAG、MCP、IM、Chrome Extension。
- 不引入 Go 服务。
- 不接入新的向量库后端。
- 不保留用户可选 `vector_only` / `keyword_only` / `hybrid` 检索模式。
- 不允许生产 Quick Q&A 在缺少 rerank、Qdrant、ParadeDB BM25 时静默降级。

## 推荐执行顺序

建议一个新窗口只做一个 TASK，按顺序执行。

1. `TASK-046`：收敛 v0.9 固定配置和默认参数。
2. `TASK-047`：固定 parent-child 切分和 child chunk 数据契约。
3. `TASK-048`：引入 ParadeDB BM25 schema / repository 边界。
4. `TASK-049`：文档处理双写 Qdrant + ParadeDB BM25。
5. `TASK-050`：固定 Quick Q&A hybrid 检索入口，移除用户模式选择。
6. `TASK-051`：rerank 强制执行和缺配置错误。
7. `TASK-052`：parent context、sources、retrieval trace 最终契约。
8. `TASK-053`：前端设置页收敛为 v0.9 固定主链路。
9. `TASK-054`：前端 Quick Q&A 展示 answer、sources、trace。
10. `TASK-055`：v0.9 端到端验收和文档更新。
