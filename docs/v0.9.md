# KnowMate v0.9 固定 RAG 主链路设计备忘

本文保留 v0.9 的长期架构决策。一次性 TASK 提示词和执行计划已清理；当前版本说明见 [v1.0](v1.0.md)，线上 Quick Q&A 链路和排障说明见 [Quick Q&A WeKnora 对齐召回链路](quick-answer-weknora-aligned-chain-2026-06-10.zh-CN.md)。

## 核心决策

v0.9 将 KnowMate 从“可配置实验型 RAG”收敛为唯一 Quick Q&A 主链路：

```text
文件上传
  -> 文档解析 / Markdown-like 清洗
  -> parent-child chunking
  -> child chunk 写入 PostgreSQL
  -> child chunk 写入 Qdrant
  -> child chunk 写入 ParadeDB BM25
  -> Query Understand
  -> Qdrant dense retrieval
  -> ParadeDB BM25 keyword retrieval
  -> RRF fusion
  -> mandatory rerank
  -> parent / neighbor context expansion
  -> context select
  -> grounded answer
  -> answer + sources + retrieval_trace
```

固定原则：

- 知识库优先：摄入、检索、回答都必须 scoped to knowledge base。
- 向量库固定 Qdrant。
- 关键词检索固定 PostgreSQL + ParadeDB `pg_search` BM25。
- 检索固定 hybrid，不向用户暴露 `vector_only` / `keyword_only` / `hybrid` 切换。
- rerank 固定开启；有候选命中但缺少可用 rerank 模型时返回中文明确错误。
- parent-child 固定开启；child 负责召回，parent/neighbor 负责回答上下文。
- 生产 Quick Q&A 不允许在缺模型、缺 Qdrant、缺 ParadeDB BM25 时静默降级。

## 固定参数

| 参数 | 值 |
| --- | --- |
| `retrieval_mode` | `hybrid` |
| `vector_engine` | `qdrant` |
| `keyword_engine` | `paradedb_bm25` |
| `embedding_top_k` | `50` |
| `keyword_top_k` | `50` |
| `vector_threshold` | `0.15` |
| `keyword_threshold` | `0.2` |
| `rrf_k` | `60` |
| `rrf_vector_weight` | `0.65` |
| `rrf_keyword_weight` | `0.35` |
| `rrf_top_k` | `30` |
| `rerank_top_k` | `8` |
| `rerank_threshold` | `0.2` |
| `parent_chunk_size` | `4096` |
| `child_chunk_size` | `384` |
| `chunk_overlap` | `80` |
| `final_context_count` | `6` |
| `max_context_chars` | `8000` |

内部候选池按知识库 scope 放大：

```text
over_retrieval_limit = min(max(rerank_top_k * 5, 50) * scope_count, 500)
```

## 数据契约

PostgreSQL chunk metadata 至少保留：

```text
tenant_id
knowledge_base_id
document_id
parent_chunk_id
chunk_id
title
content
search_text
context_header
chunk_type
position
metadata
```

Qdrant payload 至少保留：

```text
document_id
chunk_id
parent_chunk_id
knowledge_base_id
title
content
context_header
chunk_type
metadata
```

Quick Q&A `sources` 至少保留：

```text
document_id
document_title
chunk_id
parent_chunk_id
score
rerank_score
source_type
snippet
metadata
```

`retrieval_trace` 至少能解释：

```text
query_original
query_rewritten / query_normalized
query_intent
vector_hits
keyword_hits
query_expansion_hits
rrf_hits
rerank_hits
selected_contexts
model_config_used
```

## 前端约束

当前前端是 Vue 中文测试工作台，不是营销页。v0.9 后页面表达固定主链路：

- 展示 Qdrant、ParadeDB BM25、RRF、rerank、parent-child 的配置状态。
- 不展示 planned vector backends。
- 不展示关闭 rerank 或 parent-child 的开关。
- Quick Q&A 结果展示 answer、sources 和 retrieval trace。
- 错误信息必须是中文可读文本，不能渲染 `[object Object]`。
- API key 只展示配置状态和末四位，不回显完整密钥。
